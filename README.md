# TravelPulse LK

Community-based smart public transport and road condition mobile application.
SE5104 Mini Project, Group 10.

## Folder structure
- mobile-app/ : Flutter (Dart) mobile application
- backend/    : Node.js + Express.js REST API
- database/   : MySQL schema, migrations, and seed data
- docs/       : project documentation
- diagrams/   : UML and architecture diagrams

## Branch rules
- main: stable, integrated code. Changed only by pull request from develop.
- develop: integration branch. Changed only by pull request from feature branches.
- feature/*: one branch per module or task, created from develop.
